О проекте LoremFlow

Лабораторная работа №6 • Вариант 19

Веб-приложение и REST API для генерации текста-рыбы (Lorem Ipsum) с поддержкой query-параметров и валидацией входных данных.

Стек технологий: Node.js, Express, Vanilla JS, HTML5, CSS3, PWA (Service Worker + Web App Manifest).
